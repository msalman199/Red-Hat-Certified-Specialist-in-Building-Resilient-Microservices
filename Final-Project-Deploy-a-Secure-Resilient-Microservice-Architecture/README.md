## 🧠 Key Concepts

| 🔑 Concept | 📖 Description |
|-----------|---------------|
| **OpenShift Service Mesh** | Platform providing traffic management, security, resilience, and observability for microservices |
| **Multi-Tier Application** | Bookstore application composed of database, business logic, and frontend services |
| **Canary Deployment** | Gradual traffic exposure to a new service version |
| **Mutual TLS (mTLS)** | Encrypted, mutually authenticated communication between services |
| **Authorization Policy** | Rules defining which service-to-service calls are permitted |
| **JWT Authentication** | Token-based end-user authentication enforced in the mesh |
| **Circuit Breaker** | Mechanism that stops traffic to unhealthy services to prevent cascading failures |
| **Retry Policy & Timeout** | Settings that handle transient failures and bound request duration |
| **Fault Injection** | Deliberately introducing failures to test resilience behavior |
| **Distributed Tracing** | End-to-end request visibility across microservices |
| **Custom Metrics & Dashboards** | Observability tooling for monitoring system behavior |
